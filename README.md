## Website

A responsive black-and-white portfolio built with HTML, CSS, and JavaScript. Features include project filters, animated project and experience disclosures, reduced-motion support, and a portrait sharing card.

Hosted on GitHub Pages at **[kendrickthiha.me](https://kendrickthiha.me/)**. Updates to the `main` branch deploy from the repository root. GitHub Pages manages HTTPS; `CNAME` connects the custom domain.

## Local Preview

From the repository root:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Open [localhost:4173](http://127.0.0.1:4173/). No build step or package installation is required.
